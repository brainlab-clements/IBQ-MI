# IBQ-MI
Code for the Infant Behavior Questionnaire Measurement Invariance Project. 
There are two R script files. To run analysis, run IBQ_Code_Clean.R. To run IBQ scoring system for the proposed 4 factor model, run IBQ_Scoring.R

In the code, there are modifications needed (e.g., file paths, intials, data imports). Remember to change those before running code. This should be a 1 time modification.
